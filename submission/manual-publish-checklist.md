# Manual SagaPad Publish Checklist

SagaPad currently requires a Solana wallet extension in the browser. The Codex in-app browser does not show Phantom/Solana wallet options, so the publish step must be completed in a normal Chrome window where Phantom is installed.

## Links

GitHub repository:
https://github.com/wognsdl2/founder-voice-playbook

SagaPad publish page:
https://sagapad.com/skills/publish-skill

Expected SagaPad skill URL after publish:
https://sagapad.com/skills/founder-voice-playbook

## Steps

1. Open `https://sagapad.com/skills/publish-skill` in regular Chrome with Phantom installed.
2. Click `Select Wallet`.
3. Choose Phantom and connect.
4. Click `Connect GitHub`.
5. Approve GitHub access for the `wognsdl2/founder-voice-playbook` repository.
6. Paste the repository URL:
   `https://github.com/wognsdl2/founder-voice-playbook`
7. Validate the skill.
8. Set category to `Colosseum Hackathon`.
9. Confirm name is `founder-voice-playbook`.
10. Publish.

## Safety

Do not enter seed phrases or private keys anywhere.

Only approve a normal wallet connection/sign-in message for SagaPad if Phantom shows `sagapad.com` as the requesting site.
