# founder-voice-playbook

An agent skill for Solana founders who need a credible X voice, not a generic content calendar.

This skill turns a founder's project, background, audience, and natural communication style into a practical personal brand playbook:

- owned point of view
- audience map
- 3-4 content pillars
- writing style guide
- 4-week posting rhythm
- first 10 posts
- two thread outlines
- reply and quote-tweet strategy
- weekly measurement loop

It was built for the SagaPad Agentic Skills SideTrack, Topic 2: Founder Personal Brand Playbook Skill.

## Why this exists

Early Solana founders often publish from the project account and ignore the founder account. That leaves the strongest trust surface unused.

Project accounts explain features. Founder accounts build conviction.

This skill helps a founder become easier to follow by connecting three things:

1. what the founder has actually learned
2. what the product uniquely proves
3. what the target audience already cares about

## How to use

Give the agent a compact founder brief:

```text
Founder: Mina, technical founder
Project: ClearPay
Product: Solana stablecoin payments for small exporters
Audience: exporters, marketplaces, fintech operators
Style: concise, practical, mildly analytical
Arena: payments
Proof: working demo, invoice reconciliation prototype
```

Then ask:

```text
Use founder-voice-playbook to create my 4-week founder X strategy and first posts.
```

## What makes it different

The skill does not start with "post consistently." It starts by finding the founder's credible edge.

The output is designed to be useful to a busy founder:

- short posts they can publish immediately
- weekly threads with a clear angle
- reply patterns for ecosystem conversations
- measurement that improves signal without chasing empty virality
